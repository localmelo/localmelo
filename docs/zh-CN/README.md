# localmelo 文档

这里是 localmelo 的文档索引。localmelo 是一个本地个人智能体，它借助工具和记忆，在你自己的模型服务器或云端 API 上运行任务。网站位于 <https://localmelo.github.io/localmelo/>。英文索引见 [README.md](../README.md)。

<a id="start-here"></a>

## 从这里开始

- [快速开始](start/quickstart.md)：安装 localmelo，运行第一个任务，保存配置并启动网关。
- [面向智能体的 localmelo](../for-agents.md)（英文）：给编码智能体和 LLM 工具的简明入口，由 [llms.txt](../llms.txt)（英文）索引。
