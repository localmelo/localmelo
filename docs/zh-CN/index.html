localmelo

一个本地个人智能体：在你自己的模型服务器或云端 API 上，借助工具和记忆完成任务。它可以在命令行中运行，也可以作为一个小型 HTTP 服务运行。

快速开始

你需要 macOS（在 macOS 上开发和测试）或 Linux（应该也能运行，但尚未测试），以及 Python 3.11 或更高版本、Git 和 uv。不支持 Windows。用 uv 安装（也可以用 pip 安装）：

请保留目录名 localmelo：软件包就是从这个目录构建的。

在搭载 Apple 芯片的 Mac 上，还可以用 uv run python scripts/build_macos_app.py --install 构建 macOS 应用：它是网页控制台外面的一个原生窗口，从 Spotlight 打开。把窗口收起来时，一只小小的秋田犬 Melo 会趴在你的桌面上。这是开发版本，不是经过公证的下载。

启动一个模型服务器，然后运行一个任务。在搭载 Apple 芯片的 Mac 上，推荐使用本地服务器 oMLX：用 omlx serve --model-dir ~/models --port 8000 提供一个模型文件夹（快速开始给出了完整步骤）。在其他系统上，使用 Ollama，并用 ollama pull qwen3:8b 下载一个模型。答案会输出到 stdout。

-u 和 -m 是 --url 和 --model 的字母写法；旧写法 --base-url 和 --chat-model 仍然可用（旧写法对应的新写法）。

能做什么

每张卡片都会打开 GitHub 上对应的英文参考页面。

运行任务 一条命令完成一个任务：在步数上限内运行，两次尝试之间会进行反思，还可以设置运行时限；也可以运行 melo 在终端里对话：它以安静的记录显示工作：每个工具调用一行，答案完整显示，一轮改动的文件会在页脚下点出；批准写文件之前，还会显示这次写入将做出的改动；运行命令或写文件之前会先询问；还可以用 melo -c 或 melo -r 恢复该文件夹里已保存的对话；/title、/undo、/usage、/memory 和 /copy 可以命名、撤销、查看和复制对话；整段对话还可以运行在推理和召回模式下（--reasoning、--retriever 和各个召回选项）。 工具和 MCP 使用五个内置工具和本地 MCP 服务器提供的工具（网关和控制台会话有四个，没有 shell_exec；直接运行有三个）；在 Mac 上，开启浏览后，终端聊天和控制台还可以在 Safari 里阅读网页；每一步提供内置工具、模型已经调用过的工具和与任务最接近的匹配，并且只运行这些工具；子进程只拿到最小环境加上 tool_env，Python 调用在子进程中运行，时间限制可以终止它。 模型服务器 连接你自己运行的 oMLX（Apple 芯片的 Mac 上推荐）、Ollama、MLC LLM、vLLM 或 SGLang 服务器，或者 OpenAI、Anthropic、Google Gemini、NVIDIA 的 API。 网关和网页工作区 通过 HTTP 提供智能体服务，会话在重启后仍然保留；网页控制台的实时页面在 http://127.0.0.1:8401/：会话列表、每一轮为每个工具调用显示一张工作卡片、进度行、Stop，以及开发者模式下的优先级标签；页面只访问 /api。 Worker 历史 用任务说明文件启动 worker，通过显式指定的收件箱文件或工具无法写入的继承管道 fd 发送指令，并获得 JSON 结果或事件流；也可保存或导入运行，只读查看历史。 API v2 通过 /api 读取网页控制台的会话、轮次、已存事件（也有 Server-Sent Events 流）、图片 blob、提交查询、工具、授权、记忆和运行记录，也可以创建会话，开始、重试、停止和审批它的轮次；只在回环地址上提供，并且只增不改。 记忆 工作记忆、任务和步骤的历史记录与长期记忆；开启持久化后保存到 SQLite。compress 推理模式保留简短笔记，并在起始、尝试和步骤召回；启发式笔记可保留部分否定和中文陈述，但提取与来源匹配可能有误或不完整。在 Python 中可以忘掉一个任务或全部记忆。 嵌入模型设置 为长期记忆添加嵌入模型：第一次运行或配置向导会提供聊天服务器已经列出的模型，并给出 Ollama、oMLX、vLLM、SGLang 和 MLC 的步骤。 Python API 实验性 在 Python 代码中运行任务：以事件形式跟踪每一步，停止运行，审批工具调用，并把文件工具限制在一个目录内。 记忆检索 用 melo-retrieve 在带标注的查询上比较 bm25、llm 和 embedding 三种记忆检索器；compress 推理模式在循环中使用同一组检索器，由 auto 选择。 脚本和基准测试 每次运行输出一行 JSON 和固定的退出码，脚本可以放心依赖运行结果；还可以选择后续轮次如何发送或保留回复的推理（--reasoning legacy、drop、replay、compress 或 compress+replay）。

安全

工具以你的账户权限运行，并且没有沙箱。模型可以运行 shell 命令和 Python 代码，也可以读写你能访问的任何文件。在 macOS 上，worker 运行（melo worker）和保存的任务只能在自己的工作区内写文件；读取和网络不受限制。新建的记忆文件只有你能读取（权限 0600）。网关要求 bearer 令牌或浏览器会话，并拒绝非回环监听。在终端运行 melo console 获取一次性登录链接。持有令牌者能以你的权限操作；同一用户的进程之间没有隔离，浏览器 cookie 也不按 localhost 端口隔离。
