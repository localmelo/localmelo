localmelo

一个本地个人智能体：在你自己的模型服务器或云端 API 上，借助工具和记忆完成任务。它可以在命令行中运行，也可以作为一个小型 HTTP 服务运行。

请保留目录名 localmelo：软件包就是从这个目录构建的。

能做什么

每张卡片都会打开 GitHub 上对应的英文参考页面。

运行任务 一条命令完成一个任务：在步数上限内运行，两次尝试之间会进行反思，还可以设置运行时限；也可以运行 melo 在终端里对话：模型的思考、每个工具调用和运行进度都会实时显示；批准写文件之前，还会显示这次写入将做出的改动；运行命令或写文件之前会先询问；还可以用 melo -c 或 melo -r 恢复该文件夹里已保存的对话；/title、/undo、/usage、/memory 和 /copy 可以命名、撤销、查看和复制对话；整段对话还可以运行在推理和召回模式下（--reasoning、--retriever 和各个召回选项）。 工具和 MCP 使用四个内置工具和本地 MCP 服务器提供的工具（网关和控制台会话只有三个，没有 shell_exec）；每一步提供内置工具、模型已经调用过的工具和与任务最接近的匹配，并且只运行这些工具；子进程只拿到最小环境加上 tool_env，Python 调用在子进程中运行，时间限制可以终止它。 模型服务器 连接你自己运行的 Ollama、oMLX、MLC LLM、vLLM 或 SGLang 服务器，或者 OpenAI、Anthropic、Google Gemini、NVIDIA 的 API。 网关和网页工作区 通过 HTTP 提供智能体服务，会话在重启后仍然保留；网页控制台的实时页面在 http://127.0.0.1:8401/：会话列表、每个回合为每个工具调用显示一张工作卡片、进度行、Stop 和优先级标签；页面只访问 /api。 Worker 历史 可以选择保存直接运行或导入 dsh 日志，再通过本地网关 API 只读查询和筛选。 API v2 通过 /api 读取网页控制台的会话、回合、已存事件（也有 Server-Sent Events 流）、图片 blob、提交查询、工具、授权、记忆和运行记录，也可以创建会话，开始、重试、停止和审批它的回合；只在回环地址上提供，并且只增不改。 记忆 工作记忆、任务和步骤的历史记录，以及配置了嵌入服务器时的长期记忆；开启持久化后会保存到 SQLite，保存的文字会先做脱敏，长期记忆记录带类型、只有排练、用户陈述或可选的结果摘要才能写入，compress 推理模式会在内存中为每条回复保留一条简短的笔记，并在起始、尝试和步骤召回它，启发式笔记只保留真实事实并引用确立它的记录；在 Python 中还可以忘掉一个任务或全部记忆。 嵌入模型设置 为长期记忆添加嵌入模型：第一次运行或配置向导会提供聊天服务器已经列出的模型，并给出 Ollama、oMLX、vLLM、SGLang 和 MLC 的步骤。 Python API 实验性 在 Python 代码中运行任务：以事件形式跟踪每一步，停止运行，审批工具调用，并把文件工具限制在一个目录内。 记忆检索 用 melo-retrieve 在带标注的查询上比较 bm25、llm 和 embedding 三种记忆检索器；compress 推理模式在循环中使用同一组检索器，由 auto 选择。 脚本和基准测试 每次运行输出一行 JSON 和固定的退出码，脚本可以放心依赖运行结果；还可以选择后续回合如何发送或保留回复的推理（--reasoning legacy、drop、replay、compress 或 compress+replay）。

安全

工具以你的账户权限运行，并且没有沙箱。模型可以运行 shell 命令和 Python 代码，也可以读写你能访问的任何文件。新建的记忆文件只有你能读取（权限 0600）。网关没有身份验证，所以请让它只监听 127.0.0.1（默认值）：在这个地址上，它会拒绝其他网站的网页通过浏览器向它的 API 发来的请求。

请阅读安全策略（英文）和检查能做什么（英文）。
