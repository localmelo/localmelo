localmelo

一个在你自己电脑上运行的个人智能体。它借助工具干活，跨对话记忆，连接你自己的模型服务器或云端 API。

快速开始

你需要 macOS（Linux 应该也能运行；不支持 Windows），以及 Python 3.11 或更高版本、Git 和 uv。

  1. 安装

    克隆仓库，让 uv 完成安装。

  2. 运行第一个任务

    让 melo 连接你的模型服务器并提一个问题，答案会打印在 stdout。

  3. 打开主对话

    不带任务运行 melo：首次运行会找到你的服务器并保存配置。

  4. 交给它一个任务

    在对话里提出更大的工作：它会成为任务，完成后以卡片回来。

  5. 查看它记住了什么

    melo 跨对话保存笔记；你可以列出它们，或忘掉某一条。

  • 请保留目录名 localmelo：软件包就是从这个目录构建的。
  • 在搭载 Apple 芯片的 Mac 上推荐 oMLX 作为模型服务器；其他系统用 Ollama。
  • -u 和 -m 是 --url 和 --model 的简写；答案打印在 stdout 上。
  • 在搭载 Apple 芯片的 Mac 上还可以构建 App：uv run python scripts/build_macos_app.py --install。

能做什么

一个主对话，旁边是旁支对话提问，或者交代工作：更大的工作按优先级（P0 到 P5）成为任务，完成后以卡片回来。 看得见的记忆melo 跨对话记忆，新的事实取代旧的。你可以查看、编辑或删除每一条笔记。 按时运行的定时事项说一次就行，比如 every weekday at 8:30, brief me on my calendar。check-in 会告诉你什么做完了。 说清发生了什么的任务卡片说明任务怎样结束：Ready、Done, not finished 或 Needs you；任务只在它所属对话的文件夹里工作。 终端进入同一个对话输入 melo 就进入 App 里同一个主对话，/side 开始旁支对话。 显示正在运行什么的胶囊窗口收起时，Mac 上的一个小胶囊说明 melo 正在做什么。 重要操作由你批准melo 运行命令或改文件之前会先问你，并展示改动。 读网页打开浏览功能后，melo 在你能看到的 Safari 窗口里读网页。 English 和简体中文控制台和 App 支持简体中文。在设置里选择，或让“自动”跟随你的浏览器。

另外：模型服务器、HTTP API、worker 运行、Python API 和脚本。

自动模式

  • 用输入框下模型旁边的小标签选择自动，或在设置里让每个新对话都从它开始。
  • 常规步骤不问就运行；有风险的步骤和你没要求的步骤会被拦下，melo 会说明原因。
  • 点允许一次，或回复“继续”，那一步就只运行一次。
  • 步骤只在对话的文件夹里动文件，碰不到 melo 自己的登录信息：“自动”是审查员，不是围墙。
  • 任务沿用创建它的对话的模式。

指南中的自动模式

提醒

  • 用平常的话说，中文和英文都行：两小时后提醒我喝水。
  • 没说时间，melo 会问你几点，而不是自己猜。
  • 到点，主对话里的一张卡片会告诉你，已完成的提醒留在“定时”标签页里。
  • 电脑睡眠时错过了，醒来后 melo 会提醒你，并说明晚了多久。

指南中的提醒

已停止的任务可以继续

  • 步数用完的任务显示已停止，而不是失败。
  • 继续会从停下的地方接着做，并带着它之前做的事。
  • 也可以在主对话里说出任务名，melo 会立刻继续它。
  • 说“简单说一下”或“一句话”，主对话会用一两句话回答；它开始的任务也会有简短的名字。

安全

工具以你的账户权限运行，并且没有沙箱。

  • 模型可以运行 shell 命令和 Python 代码，也可以读写你能访问的任何文件。
  • 在 macOS 上，worker 运行（melo worker）和保存的任务只能在自己的工作区内写文件。
  • 在 macOS 上的“自动”模式下，一个步骤还会在写入沙箱里运行：它的文件只留在文件夹里，碰不到 melo 自己的登录信息。
  • 新建的记忆文件只有你能读取（权限 0600）。
  • 网关要求 bearer 令牌或浏览器会话，并拒绝非回环监听；melo console 会打印一次性登录链接。
  • 持有令牌者能以你的权限操作；同一用户的进程之间没有隔离，浏览器 cookie 也不按 localhost 端口隔离。

请阅读安全策略（英文）和检查的作用。
