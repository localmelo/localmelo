localmelo

一个本地个人智能体：在你自己的模型服务器或云端 API 上，借助工具和记忆完成任务。它可以在命令行中运行，也可以作为一个小型 HTTP 服务运行。

快速开始

你需要 macOS（在 macOS 上开发和测试）或 Linux（应该也能运行，但尚未测试），以及 Python 3.11 或更高版本、Git 和 uv。不支持 Windows。用 uv 安装（也可以用 pip 安装）：

请保留目录名 localmelo：软件包就是从这个目录构建的。

启动一个模型服务器，例如 Ollama，并用 ollama pull qwen3:8b 下载一个模型，然后运行一个任务。答案会输出到 stdout。

能做什么

每张卡片都会打开 GitHub 上对应的英文参考页面。

运行任务 一条命令完成一个任务：在步数上限内运行，两次尝试之间会进行反思，还可以设置运行时限；也可以运行 melo 在终端里对话：模型的思考、每个工具调用和运行进度都会实时显示，运行命令或写文件之前会先询问。 工具和 MCP 使用四个内置工具和本地 MCP 服务器提供的工具；每一步只能运行本步提供的工具。 模型服务器 连接你自己运行的 Ollama、oMLX、MLC LLM、vLLM 或 SGLang 服务器，或者 OpenAI、Anthropic、Google Gemini、NVIDIA 的 API。 网关和网页工作区 通过 HTTP 提供智能体服务，支持会话；还可以在网页工作区里使用智能体，模型来自你的服务器。 记忆 工作记忆、任务和步骤的历史记录，以及配置了嵌入服务器时的长期记忆；开启持久化后会保存到 SQLite。在 Python 中还可以忘掉一个任务或全部记忆。 Python API 实验性 在 Python 代码中运行任务：以事件形式跟踪每一步，停止运行，审批工具调用，并把文件工具限制在一个目录内。 离线检索 仅离线 用 melo-retrieve 在带标注的查询上比较 bm25、llm 和 embedding 三种记忆检索器。运行目前还不使用它们。 脚本和基准测试 每次运行输出一行 JSON 和固定的退出码，脚本可以放心依赖运行结果。

路线图

v0.1.0 里程碑计划于 2026-12-20 完成。

计划中：

  • 交互式命令行的后续部分：审批中显示改动的 diff、可以恢复的会话（melo -c、melo -r）、附加文件和 shell 命令；
  • 网关重启后仍然保留的对话，并在网页工作区里实时显示智能体的工作；
  • 把模型的推理过程保存为记忆笔记，并可切换检索方式（bm25、llm、embedding）；
  • 在一个本地模型服务器上同时运行多个任务，并优先回答你的对话；
  • 进度行上的百分比进度条，用于反复运行的任务；在重放证明它可靠之前保持关闭。

各阶段、相关议题和更新记录见路线图和更新。

安全

工具以你的账户权限运行，并且没有沙箱。模型可以运行 shell 命令和 Python 代码，也可以读写你能访问的任何文件。新建的记忆文件只有你能读取（权限 0600）。网关没有身份验证，所以请让它只监听 127.0.0.1（默认值）：在这个地址上，它会拒绝其他网站的网页通过浏览器向它的 API 发来的请求。

请阅读安全策略（英文）和检查能做什么（英文）。
