localmelo

一个在你自己电脑上运行的个人智能体。它借助工具干活，跨对话记忆，连接你自己的模型服务器或云端 API。

快速开始

你需要 macOS（Linux 应该也能运行；不支持 Windows），以及 Python 3.11 或更高版本、Git 和 uv。

  • 请保留目录名 localmelo：软件包就是从这个目录构建的。
  • 在搭载 Apple 芯片的 Mac 上推荐 oMLX 作为模型服务器；其他系统用 Ollama。
  • -u 和 -m 是 --url 和 --model 的简写；答案打印在 stdout 上。
  • 在搭载 Apple 芯片的 Mac 上还可以构建 App：uv run python scripts/build_macos_app.py --install。

能做什么

一个主对话，旁边是旁支对话提问，或者交代工作：更大的工作按优先级成为任务，完成后以卡片回来。 看得见的记忆melo 跨对话记忆，新的事实取代旧的。你可以查看、编辑或删除每一条笔记。 按时运行的定时事项说一次就行，比如 every weekday at 8:30, brief me on my calendar。check-in 会告诉你什么做完了。 说清发生了什么的任务完成的任务的卡片说明改了什么和提交；任务只在它所属对话的文件夹里工作。 终端进入同一个对话输入 melo 就进入 App 里同一个主对话，/side 开始旁支对话。 显示正在运行什么的胶囊窗口收起时，Mac 上的一个小胶囊说明 melo 正在做什么。 重要操作由你批准melo 运行命令或改文件之前会先问你，并展示改动。 读网页打开浏览功能后，melo 在你能看到的 Safari 窗口里读网页。

另外：模型服务器、HTTP API、worker 运行、Python API 和脚本。

安全

工具以你的账户权限运行，并且没有沙箱。

  • 模型可以运行 shell 命令和 Python 代码，也可以读写你能访问的任何文件。
  • 在 macOS 上，worker 运行（melo worker）和保存的任务只能在自己的工作区内写文件。
  • 新建的记忆文件只有你能读取（权限 0600）。
  • 网关要求 bearer 令牌或浏览器会话，并拒绝非回环监听；melo console 会打印一次性登录链接。
  • 持有令牌者能以你的权限操作；同一用户的进程之间没有隔离，浏览器 cookie 也不按 localhost 端口隔离。

请阅读安全策略（英文）和检查的作用。
