localmelo

一个本地个人智能体：在你自己的模型服务器或云端 API 上，借助工具和记忆完成任务。它可以在命令行中运行，也可以作为一个小型 HTTP 服务运行，支持 Ollama、MLC LLM、vLLM、SGLang 和云端 API。

早期预览版（pre-alpha）

快速开始

你需要 macOS（在 macOS 上开发和测试）或 Linux（应该也能运行，但尚未测试），以及 Python 3.11 或更高版本、Git 和 uv。不支持 Windows。用 uv 安装（也可以用 pip 安装）：

请保留目录名 localmelo：软件包就是从这个目录构建的。

启动一个模型服务器，例如 Ollama，并用 ollama pull qwen3:8b 下载一个模型，然后运行一个任务。答案会输出到 stdout。

能做什么

每张卡片都会打开 GitHub 上对应的英文参考页面。

运行任务 一条命令完成一个任务：在步数上限内运行，两次尝试之间会进行反思，还可以设置运行时限。 工具和 MCP 使用四个内置工具和本地 MCP 服务器提供的工具；每一步只能运行本步提供的工具。 模型服务器 连接你自己运行的 Ollama、MLC LLM、vLLM 或 SGLang 服务器，或者 OpenAI、Anthropic、Google Gemini、NVIDIA 的 API。 网关和网页界面 通过 HTTP 提供智能体服务，支持会话，并附带一个用来试用模型的简单网页。 记忆 工作记忆、任务和步骤的历史记录，以及配置了嵌入服务器时的长期记忆；开启持久化后会保存到 SQLite。 脚本和基准测试 每次运行输出一行 JSON 和固定的退出码，脚本可以放心依赖运行结果。

  • 网关重启后仍然保留的对话，并在网页工作区里实时显示智能体的工作；

安全

工具以你的账户权限运行，并且没有沙箱。模型可以运行 shell 命令和 Python 代码，也可以读写你能访问的任何文件。网关没有身份验证，所以请让它只监听 127.0.0.1（默认值）。

请阅读安全策略（英文）和检查能做什么（英文）。

早期预览版（pre-alpha）：在 v0.1.0 之前，命令和 API 都可能变化。
