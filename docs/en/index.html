localmelo

A local personal agent that runs tasks with tools and memory on your own model server or a cloud API. It runs from the command line or as a small HTTP service, and talks to Ollama, MLC LLM, vLLM, SGLang or a cloud API.

pre-alpha

Quick start

You need Python 3.11 or later, Git and uv. localmelo is developed and tested on macOS; it should also work on Linux, and Windows is not supported. Install it with uv (or with pip):

Keep the directory name localmelo: the package is built from it.

Start a model server, for example Ollama with a model pulled by ollama pull qwen3:8b, and run a task. The answer is printed on stdout.

What you can do

Each card opens the matching reference page on GitHub.

Run tasks Run one task per command, within a step budget, with reflection between attempts and an optional time limit. Tools and MCP Use four built-in tools and the tools of local MCP servers; each step runs only the tools it offered. Model servers Connect to Ollama, MLC LLM, vLLM or SGLang servers that you run, or to the OpenAI, Anthropic, Google Gemini or NVIDIA API. Gateway and web UI Serve the agent over HTTP with sessions, plus a small web page for trying models. Memory Keep working memory, a history of tasks and steps, and long-term memory with an embedding server, saved to SQLite when you turn persistence on. Scripts and benchmarks Read one JSON line per run and a fixed exit code, so scripts can rely on the outcome.

Security

Tools run with your account's permissions, and there is no sandbox. The model can run shell commands and Python code, and read or write any file you can. The gateway has no authentication, so keep it on 127.0.0.1 (the default).

Read the security policy and what the checks do.
