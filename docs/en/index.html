localmelo

A personal agent that runs on your own computer. It works with tools, remembers across chats and talks to your own model server or a cloud API.

pre-alpha
Get started GitHub ↗

Quick start

You need Python 3.11 or later, Git and uv on macOS (Linux should work; Windows is not supported).

  • Keep the folder name localmelo: the package is built from it.
  • On a Mac with Apple silicon, oMLX is the recommended model server; elsewhere, Ollama.
  • -u and -m are short for --url and --model; the answer prints on stdout.
  • On a Mac with Apple silicon you can also build the app: uv run python scripts/build_macos_app.py --install.

What's new and what changed.

Security

Tools run with your account's permissions, and there is no sandbox.

  • The model can run shell commands and Python, and read or write any file you can.
  • On macOS, a worker run (melo worker) and a saved task can write only in their workspace.
  • New memory files are readable only by you (mode 0600).
  • The gateway requires a bearer token or browser session and refuses non-loopback binds; melo console prints a one-use link.
  • A token holder can act as you; same-user processes are not isolated, and browser cookies are not isolated by localhost port.

Read the security policy and what the checks do.
